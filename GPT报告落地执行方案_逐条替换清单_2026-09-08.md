## 一、执行总原则（三条，所有替换均遵守）

1. **去假存真**：不新增任何"体验证据"细节（不编样本量、不编审计时长、不编验证链）。缺证据的强断言 → 删除，或改写为（a）平台宣称归因、（b）用户报告归因、（c）指向读者自己可以去验证的公开工件（如 Keen 不可删评论账本、PG Journeys 公开台账）。
2. **单一数据源**：所有站点计数从内容集合动态生成（新建 `src/lib/siteStats.ts`），消灭 offers.ts 里的过期硬编码。
3. **归因分层语言**（全站通用替换规则）：

| 不写 | 改写为 |
|---|---|
| Psychic X can tell you what your partner feels | Readers frame this as intuitive insight into…; we treat it as an interpretive service |
| 91% accuracy（裸数字） | a platform-reported 91% accuracy score（归因给平台） |
| proven / mathematically destined | readers describe it as… / an interpretive lens, not a provable claim |
| Independently tested（badge） | Independently researched |
| Reddit users verified X | （删除）或指向不可篡改的公开账本让读者自查 |

### P1-1 建立 `src/lib/siteStats.ts`（数字唯一事实源）

```ts
// src/lib/siteStats.ts — 唯一的站点计数事实源
const readerModules = import.meta.glob('../content/readers/**/*.md', { eager: true }) as Record<string, any>;

const perPlatform: Record<string, { count: number; sum: number; rated: number }> = {};
for (const [, mod] of Object.entries(readerModules)) {
  const p = mod.frontmatter?.platform;
  if (!p) continue;
  perPlatform[p] ??= { count: 0, sum: 0, rated: 0 };
  perPlatform[p].count += 1;
  const r = Number(mod.frontmatter?.rating);
  if (Number.isFinite(r) && r > 0) { perPlatform[p].sum += r; perPlatform[p].rated += 1; }
}

export const siteStats = {
  total: Object.values(perPlatform).reduce((s, v) => s + v.count, 0),
  count: (p: string) => perPlatform[p]?.count ?? 0,
  avgRating: (p: string) => {
    const v = perPlatform[p];
    return v?.rated ? Number((v.sum / v.rated).toFixed(2)) : undefined;
  },
};
```

import fs from 'node:fs'; import path from 'node:path';
const out = {};
function walk(dir) {
  for (const f of fs.readdirSync(dir, { withFileTypes: true })) {
    const p = path.join(dir, f.name);
    if (f.isDirectory()) walk(p);
    else if (f.name.endsWith('.md')) {
      const txt = fs.readFileSync(p, 'utf8');
      const fm = txt.split('---')[1] || '';
      const platform = /platform:\s*['"]?([a-z-]+)/.exec(fm)?.[1];
      const rate = /\$(\d+(?:\.\d+)?)\s*\/\s*min/.exec(txt)?.[1];
      if (platform && rate) (out[platform] ??= []).push(Number(rate));

}

for (const [p, a] of Object.entries(out)) {
