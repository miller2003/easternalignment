## 棕底黑字 CTA 按钮修复（根因 + 全面修复）
- **根因（截图像素级确认）**：按钮文字色 = #8B6F4E（--color-primary），背景 = accent 渐变。罪魁是 global.css 的 `.prose a:not(.btn):not(.card):not(.card *)` 链接规则——3 个 :not() 叠加特异性达 (0,4,1)，会覆盖任何**不带 .btn 类、且渲染进 .prose 的按钮锚点**的白字声明（组件作用域样式仅 (0,3,0)，必输）。
- **受害面**：InlineCta（JS 注入 .prose 第 2 个 h2 前，全站 review/comparison/guide 页）+ ScorePanel（3 平台 hub 经 slot 渲染进 .prose）。两者此前各有"prose-leak reset"但特异性算错，修复一直无效——这就是用户反复看到棕底棕字的原因。
- **三层修复**：① 根因：global.css prose 规则追加 `:not([class*="btn"]):not([class*="cta"])`，类名含 btn/cta 的锚点一律豁免（全覆盖、防未来）；② 加固：InlineCta/ScorePanel/EndCTA/LeftSidebar/EsLeftSidebar/SidebarDealCard/StickyCTA 共 7 个组件的棕底按钮 color 补 `!important`（与 .btn--primary/.btn-book 既有模式一致）；③ 直改：3 平台 hub 的 `.roundup-badge`（真·棕底深字 badge）color: var(--color-primary-dark) → #fff。
- **教训/约定**：以后新建按钮锚点，类名必须含 "btn" 或 "cta"，且棕底白字声明一律带 !important。
- 构建：沙箱 build 依旧不可用，已用 CODEBUDDY_SESSION_ID= CLAUDE_SESSION_ID= 置空方式本机后台构建（结果待确认）；生效需 rebuild + redeploy。
