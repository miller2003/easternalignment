### 核心策略结论
玄学垂直是"三重困境"：准 YMYL（金钱+情感脆弱人群）+ 无第三方执业资格可挂 + 服务不可证伪。
业内默认解法（虚构作者 persona）有效但是最脆的一环——QRG 要求评估员用外部独立信息源验证作者声誉。
→ **承重结构迁移：从单点 persona → 证据链 / 机构实体 / 外部声誉 三脚架。** persona 保留为叙事载体但不再承重。

### 优先级（ROI 排序）
- P0 证据资产化：建 /methodology/ + 5 类标准证据图（聊天首屏打码 / 计时计费 / 账单 / 退款工单 / 客服对话）+ `lastVerified` 字段 + 先跑 3 篇样板
- P1 机构实体化：补 Organization.sameAs + foundingDate + contactPoint；建 /editorial-policy/ 含**更正日志**（竞品几乎无人做）
- P2 引入真实外部审校者（破 Expertise 无 credential 的唯一办法）：执业 reader 做 advisory reviewer；**心理咨询从业者审校情感依赖/边界类内容**（资格可验证，且直接回应 YMYL 风险点）
- P3 数据研究 + Digital PR：手上 150+ 深度 review 数据是独有矿（实付价格年报 / 响应时长分布 / 顾问流失率追踪）。BuzzStream 2026：数据型选题是 95.9% 从业者首选 tactic
- P4 Trust 细节：把已在做的**顾问流失监控显性化**成公开声明（现在是白扔的信号）

### 关键联动
P0–P2 同时是 GEO 信号——GEO 四要素中的"具体数字锚点"和"信息增量"正由 P0 证据资产直接供给。一次投入两个战场。
约束：补证据图时注意 chrome 稀释红线（620–740 词；正文 <1500 词时 chrome>30% 禁加 CTA）。

### 明确排除的做法
买假社交账号填 sameAs / 堆 credential 徽章（行业无公认认证，反暴露问题）/ 为放图改动正文布局（既有红线）/ 全站一次铺开（先 3 篇样板）。

### 验收口径

- 全程盯 PostHog `affiliate_link_click` 的**每页**转化，不看总量（E-E-A-T 作用点在页面层，总量会被流量增长掩盖）
