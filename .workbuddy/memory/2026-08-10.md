## 操作坑：孤儿 build 进程导致 astro build 假死（重要，防复发）
- 本环境会积累多个孤儿 `npm run build` / `astro.mjs build` 进程（前几次会话遗留），新 build 会和它们抢 dist/ 而假死（表现：astro build 卡住不动、dist 只有旧 12+5 页、最长见过 3 小时不结束）。
- 排查：`ps -ef | grep -iE "astro.mjs|npm run build"`。
- 清理：`pkill -9 -f "astro.mjs build"; pkill -9 -f "npm run build"`；若 pkill 不生效则 `kill -9 <PID>` 具体进程。清理后单次 build 约 8 秒出 200+ 页。
- 构建监控不要用 `| tail -60`（缓冲到结束才吐，看不出卡哪）；直接后台跑 + TaskOutput 看流式日志。
- 必须 `CODEBUDDY_SESSION_ID= CLAUDE_SESSION_ID=` 关 safe-delete shim 才能构建成功。
