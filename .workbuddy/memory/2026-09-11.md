## Favicon 优化（Google SERP 图标看不清 / 颜色太淡）

**用户诉求**：Google 搜索结果里站点 logo 图标颜色太淡、模糊，要求加深、加锐度、鲜艳抓眼球，以提升 SERP 点击率。

**根因（用数据确认，非猜测）**：
- `public/favicon.ico` 只有 **单帧 16×16**（539 B）。Google 明确不建议提供 16×16，要求方形且为 48 的倍数 → 被放大必然糊。
- `favicon.png` 是 192×192（尺寸合规），但**画面是奶油白纸上的粉彩水彩**。在 48px 降采样下平均亮度仅 **206/255**，距纯白只有 **49 级** → Google 白色结果卡片上几乎不可见。`apple-touch-icon.png` 180×180 同一张画。
- 结论：单纯"加深+锐化"救不了——米白纸占画面 90% 以上，压深只会把整块变灰。

**已建工具**（可复跑）：`scratch/favicon-20260911/`
- `gen.py` — 管线：内容自动裁方 → 4 类处理（原图增强 / 水彩抠纸压深蓝底 / 粗描重绘 / 深色重绘）→ 10 档尺寸 LANCZOS + 后置 unsharp → 决策预览图 → 每个候选出齐 `deploy/<tag>/` 全套（favicon.ico 四帧 16/32/48/64、favicon.svg、favicon-96x96.png、favicon.png 192、apple-touch-icon 180、android 192/512）。
- `sixteen.py` — 16px 放大 10 倍的"决定性对比图"（浅色 chip + 深色 chip）。
- `svgcheck.cjs` — 用项目内 `sharp` 把 SVG 栅格化，与 PIL 位图逐格比对，确认 SVG 与 PNG 一致。
- 依赖：`C:\Users\samja\.workbuddy\binaries\python\envs\default`（Pillow 12.3 + numpy）。
- 输出：`out/PREVIEW_all.png`、`out/DECISION_16px.png`。

**16px 实测排序**：C(深蓝底粗描) > E(米白底深色) > D(夕阳渐变) > A(仅增强) > B(水彩压底) > 现状。
- D 的太阳与同色渐变底糊在一起，太阳轮廓最差。
- **横向否决项**：透明底 + 细描边方案（F）被否决——描边 12/1024 单位在 16px 下只有 0.19px，完全消失。要在 16px 存活，描边需 ≥64 单位（=1px），即与笔画同宽。**结论：16px 下靠线描边无效，必须靠实心色块。**
- 关键指标（48px 降采样）：现状 vs 白底对比 48.8 → C 为 **176.3**。

## 后续（用户回复 + 落地）

用户回复：favicon 选 **A 方向并要求"继续加深颜色"**；logo.jpg **不要深色版**（保持现状，未改动）。

于是做了三轮加深阶梯，每轮都用数据证伪了上一轮的假设：
1. **RGB 整体压暗** → 整块发灰，米白纸压不出对比。
2. **HSV 降 V（value）** → 暖色变干枯褐（同尺寸同彩度）。
3. **只提彩度（saturate/contrast，不压暗）** → 颜色鲜艳了，但 16px 仍糊。
4. **决定性测量**：该水彩的**墨迹覆盖率只有 ~18%**（对比 E 方案 48.6%），所以 16px 每个像素 ~82% 是白纸，**再怎么调色都没用**。
5. **posterise（压平 V 通道）** 才是有效杠杆 → P1/P2/P3 三档，太阳从渐变淡金变成实色橙，光线变实色红/绿/蓝，同时**保留水彩笔触与浅底**。
