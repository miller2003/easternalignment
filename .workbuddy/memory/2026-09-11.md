## 🔴 重大自我更正：`/go/*` 的 CF 规则（14:20）

**用户反馈**：那条 `/go/` 规则是他**自己加的**，目的是防 bot 直连污染联盟后台；他大量流量来自 ChatGPT App 内浏览器，怕被拦。

**逐头隔离实验结果**（`scratch/audit_20260911/header_matrix.py`、`referer_isolate.py`、`easub_test.py`）——该规则**与浏览器指纹完全无关**：
```
iOS Safari UA 仅此 / +Accept / +Accept+Lang          -> 403 质询（指纹头给全也没用）
iOS Safari UA + 只有同域 Referer（无 Accept）          -> 200 ✅ 决定性
同域 Referer 只到域名 / www 子域 / /go/ 自身           -> 200 ✅
chatgpt.com / google.com / 垃圾 Referer               -> 403
无 Referer + ?ea_sub=abc.123（任意非空值）             -> 200 ✅ 第二凭证
无 Referer + 无 ea_sub（纯直连）                       -> 403 ← 正是要挡的 bot
```
**结论：规则只认「同域 Referer」或「非空 `?ea_sub=`」**。

**为什么真人点击两条都满足**：
- 同域 Referer：点击处理器 `e.preventDefault()` 后导航到相对路径 `/go/<slug>/`（`PostHog.astro:121,181,192-194`）→ 同源导航必然带 Referer；全站 `Referrer-Policy: strict-origin-when-cross-origin` 对同源发完整 URL；全站 `noreferrer`/`referrerpolicy` 命中 **0**（src/public/functions/dist 全扫）。
- `?ea_sub=`：`PostHog.astro:179-181` 无条件拼接，源码注释「ea_sub 必须永远存在——真人点击的唯一凭证」。

**⇒ ChatGPT/Instagram/Pinterest 等 App 内置浏览器不受影响**（就是系统浏览器内核：iOS Safari View Controller / Android Chrome Custom Tabs，同源导航照常带 Referer；ea_sub 更是与浏览器无关）。

**⇒ 我初版报告的两条错误已撤回**：① "App 内置浏览器会被拦"的 P1 定性；② "给 `/go/*` 加 WAF Skip"的建议（照做会把 bot 直连放回来，与用户意图相反）。报告已整体重写该节并标注粗体更正。

**新增 P3-8**：`public/_headers` 注释称 `/go/*` 为 `referrer-policy: same-origin`（"不向联盟泄露来源"），但该文件 `/go/*` 块**没有这一行**（git 全历史证实 `same-origin` 只在注释里）；线上带 Referer 访问 `/go/` 实际返回 `strict-origin-when-cross-origin`（继承 `/*`）→ 跳联盟时会发 `Referer: https://easternalignment.com/`。影响近零，但注释描述的是不存在的配置。**另注**：无 Referer 时看到的 `same-origin` 其实来自 403 挑战页自身的响应头 —— 记一条教训：**基于响应头的结论必须同时确认状态码是 200**。
