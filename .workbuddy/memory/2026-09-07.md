## Bing Webmaster「报错」诊断（2026-09-07）

用户截图 BWT 三条 Recommendation 问是不是报错。实测结论：

- **sitemap 实际存在且可达**：`/sitemap-index.xml` → `/sitemap-0.xml` 均 HTTP 200（curl 默认 UA 会被 Cloudflare 403，带浏览器/bingbot UA 正常——测量 sitemap 必须带 UA，否则误判）。

- 修复路径：①BWT → Sitemaps 手动提交 sitemap-index.xml（立即消红条）；②Cloudflare 关「管理 robots.txt / Content Signals Policy」（注意权衡：托管版正在 block AI 训练爬虫，但按 GEO 策略 ai-input/检索类未 block，影响有限）；③IndexNow 走 Cloudflare Crawler Hints 零代码；④外链警告属长期工程不急。
