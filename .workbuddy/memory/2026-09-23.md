## TUNE 开发者门户核查（13:07）

- 用户要求核查 https://developers.tune.com/affiliate 是否有「实时获取平台解读师在线状态」的功能。
- **结论：没有**。该门户是 TUNE/HasOffers 联盟追踪平台，业务域是 aff 归因与结算，与解读师/顾问在线状态无关。全站无 readers / advisors / psychics / presence / availability 资源。
- Affiliate API 结构（Affiliate_ApiKey 索引页）：**24 个 controller**——AdManager、Affiliate、AffiliateBilling、AffiliateUser、Alert、ApiKey、Application、BrandDesign、BrandInformation、Dne、Goal、Notification、NotificationCenter、Offer、OfferFile、OfferPixel、OfferTargeting、OfferUrl、PrivacyPolicy、Report、RingRevenue、SavedReports、ScheduledOfferChange、UserPreferences；**49 个 model**。
- 报表仅 3 个方法：getAffiliateCommissions / getAffiliateReferrals / getConversions（聚合口径，非实时）。
- 唯一"近实时"能力：`Affiliate_NotificationCenter`（createEventSubscription / deleteEventSubscription / findAllEventSubscriptions / findAllDeliveryMetrics）+ `WebhookEndpoint` 模型，event_class + target_class + webhook_endpoint_id + deliver_via_email，推送的是联盟侧事件，**不含解读师在线状态**。
- 接入方式：`https://NETWORKID.api.hasoffers.com/Apiv3/json?Target=...&Method=...&api_key=...`；需 network 开启 Affiliate API 权限（可手动审批）。Getting Started 页 last updated **2018-10-12**。
- 门户另外 3 个产品：Network API（41 controller，含 Conversion / Optimizer / RawLog / InsertionOrder）、Advertiser API、JavaScript SDK。Network API 也无任何在线状态相关 controller。
- 与本站的关系：/go/ 跳转链路要拿"解读师在线状态"只能从 Kasamba/Keen/PG 平台侧解决（前端渲染，非开放 API）；TUNE 侧只能做转化/佣金对账与 webhook 告警——且本站后台是 barges，TUNE 这套要另开 key 才有意义。
