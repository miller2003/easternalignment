## 修复：浏览器「返回上一页」时页面从顶部落下（用户报障）

**根因**：`src/styles/global.css:122` 的 `html { scroll-behavior: smooth }`。浏览器回退时在
**根元素**上恢复滚动位置，根元素开了平滑滚动 → 恢复动作被动画化。headless 实测轨迹：0 → 4200px
跨越 42 个中间帧（约 1s 滑行）。（注：ES 侧边栏 TOC 的 `window.scrollTo({behavior:'smooth'})`
显式传参，不受此 CSS 影响，所以不能靠删 CSS 解决问题而不伤锚点滚动。）

**修法**（新增 1 组件 + 1 条 CSS 规则）：
- `src/components/ScrollRestoreGuard.astro`（`is:inline` 脚本，必须在 `<head>`）：首帧前给 `<html>`
  打 `ea-scroll-instant` → 回退恢复瞬时；首次真实用户意图（pointerdown/keydown/wheel/touchstart）
  解除 → 锚点点击仍平滑；`pagehide` 时重新武装 → **bfcache 恢复的页面也不会再滑**（bfcache 不重跑
  head 脚本）。监听器全程保留，bfcache 复活后可再次解除。
- `global.css` §2 新增 `html.ea-scroll-instant { scroll-behavior: auto }`（特异性 0,1,1 胜过 `html`）。
- 已挂到 `BaseLayout.astro` / `EsBaseLayout.astro`（两者是本站唯一根布局；`/go/` 中转页与
  `/content-manager.html` 无需挂）。

**验证**（`scratch/scroll-back-verify.mjs`，可复用回归工具）：A 回退 → 4200→4200、**0 中间帧** PASS；
B 锚点点击 `#matrix` → 27 中间帧、仍平滑 PASS；C 状态机（load 武装 auto / 交互后 smooth / pagehide 复武装）
PASS。构建 770 页，守卫覆盖：guides 113/113、comparisons 5/5、es 75/75、reviews 246/248（差的 2 个是
kasamba-psychics/keen-psychics 重定向存根）、其余 321 个缺项全是 `/go/` 中转页。
