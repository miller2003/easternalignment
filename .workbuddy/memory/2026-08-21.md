- **CF Pages 报错**：`lorrie-c.md:72:91 unidentified alias "*ANF353**"`——YAML 解析器把 `**ANF353**`（markdown 粗体）当成非法 alias。

- **教训**：
  - Python 正则 `\s*$` + `re.MULTILINE` 的组合是**陷阱**——`$` 在 MULTILINE 下匹配每行行尾，不是文件末尾。要匹配文件末尾必须用 `\Z`（不受 MULTILINE 影响）。
  - 批量改文件后验证不能只看末尾——要检查文件**开头**结构（frontmatter open/close）是否完整。
  - `grep -c "^---$" >= 2` 不够——要检查第 2 个 `---` 的**位置**（frontmatter close 应在前 80 行内）。
