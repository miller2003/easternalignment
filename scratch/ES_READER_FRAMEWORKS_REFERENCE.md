## 一、两篇共用的通用编辑装置

### 1. "仪式名 = 灵性血脉宣言" 信任钩子
- **手法**：不把名字当品牌，而把它解读为"灵性传承的公开宣言"，声称在对应文化圈（afro-diasporic / yoruba）有真实重量。
- **作用**：与通用化名（"Mystic Star / Psychic Light / Spiritual Grace"）拉开距离，制造"真有其人 / 真有其传统"的可信感。
- **复用模板（西语）**：
  > "En el mercado de videncia en línea, los nombres son frecuentemente intercambiables: Mystic Star, Psychic Light, Spiritual Grace. [Nombre] es algo fundamentalmente distinto. [分解名字含义] — no es un nombre inventado, es una declaración de vocación espiritual que dentro del mundo [tradición] tiene un peso cultural real."

### 2. "明贬暗褒" 诚实裂隙（信任装置）
- **手法**：只提无关痛痒的小问题或真实但可管理的缺点，且其解法**强化**推荐。
- **Oshun 例**：明确区分"在线解读师 ≠ santera/palera 提供正式远程仪式"——提供的是受传统启发的灵性指导，不是 Regla de Ocha 仪式。这个诚实边界反而增信。
- **复用模板**：在 review 中加一段
  > "Sin [cosa que no ofrece]: conviene aclarar que X es [rol acotado], no [rol exagerado]. Lo que ofrece es [beneficio honesto], no [promesa imposible]. La distinción importa."

### 3. "Para quién / Para quién no" 双栏结构
- **强制收尾**：明确谁该用、谁不该用。这是转化优先内容的标准结构，既显客观又守住"净读仍是推荐"。
- **模板**：
  - "Para el nicho que cubre — [audiencia específica] — X es un recurso que no tiene equivalente en ninguna plataforma anglosajona."
  - "No es para ti si: [contexto que haría la profundidad innecesariamente compleja]."

## 二、Candelifera Laveau 框架（灵媒 / 通灵 / 阿卡西记录 角度）

- **文化锚**：espiritismo caribeño + Marie Laveau（Nueva Orleans vudú）血脉引用。
- **专长簇**：mediumnicidad directa（直接通灵）、registros akáshicos（阿卡西记录）、Tarot、comunicación con familiares fallecidos（与逝者沟通）。
- **适用场景**：duelo（哀悼）、separaciones、vínculos kármicos difíciles。
- **资历钩**：30+ años de práctica。
- **定价姿态**：premium（$3.99–$5.99/min）反映专精。
- **转化收尾**：建议预算紧 / 初次探索的用户"先试更便宜的 reader"——把缺点（贵）转成横向导流，不伤净推荐。
- **SEO 标题范式**：`{Nombre} Reseña — {Plataforma} | Médium, Espiritismo y Registros Akáshicos`
- **正文钩子范式**："{Nombre}: Por Qué el Nombre Importa Antes de la Primera Sesión"

## 三、Oshun Aluna 框架（Yoruba / 非裔古巴 / Baraja Española / 灰烬占卜 角度）

- **文化锚**：Yoruba / afrocubano；名字 = Oshún 保护下的灵性签名。
- **专长簇（同时三种系统 = 稀缺性卖点）**：espiritualidad yoruba、Baraja Española、espodomancia（灰烬 / 尘占卜）、Tarot。
- **适用场景**：prosperidad económica（财运）、bloqueos emocionales、guía espiritual culturalmente específica。
- **诚实边界（明贬暗褒）**：在线解读师，非 santera/palera，不做远程正式仪式。
- **差异化**：anglophone 平台无等价物。
- **转化收尾**：适合有 afrocaribeño 纽带或真诚好奇 Yoruba 传统的 LATAM 用户；不适合无该文化背景、只想要标准 Tarot 的人（深度反而冗余）。
- **SEO 标题范式**：`{Nombre} Reseña — {Plataforma} | Espiritualidad Yoruba y Baraja Española`
- **正文钩子范式**："{Nombre}: El Nombre que Lo Dice Todo"

## 四、为真实新解读师落地时的检查清单

1. **必须是真实可验证的 reader**（有真实主页 / 有 offer 可生成深层链接）。绝不虚构。
2. 选一个**文化 / 传统锚点**（如 yoruba、espiritismo、Baraja Española）作为差异化卖点。
3. 套用"名字 = 血脉宣言"钩子（仅当名字确有文化含义；否则换其他信任装置）。
4. 加一段**诚实边界**（明贬暗褒），强化而非劝退。
5. 强制 **Para quién / Para quién no** 双栏。
6. **头像**：真实平台头像（Purple Garden / Purple Ocean 用 tokenized CDN 或 og:image；Psíquicos 需用户本机截图，sandbox 无法可靠抓取）。
7. **offer 可用性**：Purple Garden = offer 30；Purple Ocean / Psíquicos 当前**无 TUNE offer**，无法生成深层链接——生成前先确认，否则该 reader 不能挂 affiliate CTA。
